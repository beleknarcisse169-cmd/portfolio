# Portfolio AppSec Pentester

Portfolio statique single-page en HTML/CSS/JavaScript vanilla, pensé pour présenter un profil AppSec Pentester avec un design sombre, responsive et prêt pour GitHub Pages.

## Fichiers

- `index.html` : structure principale de la page
- `style.css` : thème visuel, responsive et animations
- `script.js` : interactions (menu mobile, typing effect, reveal on scroll)

## Personnalisation

Avant publication, remplacez les éléments marqués `[TODO]` par vos informations personnelles :

- Nom
- Email professionnel
- Liens LinkedIn et GitHub
- Certifications exactes
- Liens réels vers études de cas, projets ou articles

## Déploiement sur GitHub Pages

1. Poussez le contenu du dépôt sur la branche `main`.
2. Ouvrez **Settings** > **Pages** dans le dépôt GitHub.
3. Dans **Build and deployment**, choisissez **Deploy from a branch**.
4. Sélectionnez la branche **main** et le dossier **/(root)**.
5. Enregistrez, puis attendez la publication.
6. Votre site sera disponible à l'URL GitHub Pages affichée dans la section Pages.

## Développement local

Comme il s'agit d'un site statique, vous pouvez simplement ouvrir `index.html` dans un navigateur pour une vérification rapide, ou servir le dossier avec un serveur local de votre choix.
